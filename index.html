¿Qué es y cómo funciona una Página Web?

Una página web no es magia; es un conjunto de archivos de texto que tu navegador (Chrome, Safari, Edge) sabe cómo interpretar y dibujar en la pantalla.

La Arquitectura: Frontend y Backend

Frontend (Lado del Cliente): Es todo lo que ves y tocas. Se construye con:

  • HTML: El esqueleto y contenido (textos, imágenes).
  • CSS: La ropa y maquillaje (colores, diseño, Bootstrap).
  • JavaScript: El cerebro y los músculos (animaciones, clics, lógica en el navegador).

Backend (Lado del Servidor): Lo que ocurre tras bambalinas. Involucra bases de datos (donde se guardan tus usuarios y contraseñas) y lenguajes de servidor (PHP, Python, Node.js) que procesan la información antes de enviarla a tu pantalla.

DNS, Dominios y Hosting

Para que una web exista en internet, necesita infraestructura:

  • El Dominio: Es el nombre (ej. google.com). Es como la dirección de tu casa.
  • El Hosting: Es el servidor físico encendido 24/7 donde se guardan tus archivos HTML y fotos.
  • DNS (Domain Name System): El directorio telefónico que traduce "google.com" a direcciones IP numéricas.

Dominios, Hosting y Navegadores

1. El Dominio

Es la dirección fácil de recordar que los usuarios escriben en el navegador (ejemplo: www.google.com).

2. El Hosting

Es el espacio físico en un servidor donde se guardan todos los archivos, imágenes y bases de datos.

3. El Navegador Web

Es el software que interpreta el código (HTML, CSS, JS) y lo muestra gráficamente (Chrome, Firefox, Edge).

7. CSS Selectores y unidades de medida

CSS define cómo se visualiza el contenido HTML en la pantalla. Funciona mediante reglas que enlazan un selector con las propiedades y valores de estilo que se aplicarán.

Sintaxis básica

selector {
  propiedad: valor;
}

Selectores

p { }         /* por etiqueta */
.clase { }    /* por clase */
#id { }       /* por id único */
a:hover { }   /* pseudoclase */
div p { }     /* descendiente */
