¿Qué es y cómo funciona una Página Web?

Una página web no es magia; es un conjunto de archivos de texto que tu navegador (Chrome, Safari, Edge) sabe cómo interpretar y dibujar en la pantalla.

La Arquitectura: Frontend y Backend

🎨 Frontend (Lado del Cliente): Es todo lo que ves y tocas. Se construye con:

  • HTML: El esqueleto y contenido (textos, imágenes).
  • CSS: La ropa y maquillaje (colores, diseño, Bootstrap).
  • JavaScript: El cerebro y los músculos (animaciones, clics, lógica en el navegador).

⚙️ Backend (Lado del Servidor): Lo que ocurre tras bambalinas. Involucra bases de datos (donde se guardan tus usuarios y contraseñas) y lenguajes de servidor (PHP, Python, Node.js) que procesan la información antes de enviarla a tu pantalla.

DNS, Dominios y Hosting

Para que una web exista en internet, necesita infraestructura:

  • El Dominio: Es el nombre (ej. google.com). Es como la dirección de tu casa.
  • El Hosting: Es el servidor físico (una computadora muy potente) encendido 24/7 donde se guardan tus archivos HTML y fotos. Es como el terreno donde construyes tu casa.
  • DNS (Domain Name System): Los servidores en internet no entienden letras, entienden direcciones IP (ej. 192.168.1.1). El DNS es el directorio telefónico que traduce "google.com" a esos números mágicos para que tu navegador sepa a qué servidor conectarse.

Dominios, Hosting y Navegadores

Para que una página web exista en internet y pueda ser visitada por cualquiera, necesita tres componentes fundamentales adicionales a su código:

1. El Dominio

Es la dirección fácil de recordar que los usuarios escriben en el navegador (ejemplo: www.google.com). Traduce las complejas direcciones IP numéricas en palabras legibles.

2. El Hosting (Alojamiento)

Es el espacio físico en un servidor (una computadora especial conectada a internet 24/7) donde se guardan todos los archivos, imágenes y bases de datos que componen la página web.

3. El Navegador Web

Es el software que interpreta el código (HTML, CSS, JS) almacenado en el hosting y lo muestra gráficamente. Ejemplos populares son Google Chrome, Mozilla Firefox, Safari y Microsoft Edge.
